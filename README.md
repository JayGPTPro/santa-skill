# The Santa Skill

Turn an Amazon listing secondary images into Christmas versions before Q4. The product stays untouched, the main image is never changed.

## Install

    npx skills add JayGPTPro/santa-skill -g

## Run

    /santa-skill B0GYY18GYC

Needs OPENAI_API_KEY in your environment (gpt-image-2, verified OpenAI org).

More: https://jaygptpro.com/claude/santa-skill.html
